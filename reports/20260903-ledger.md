# Ludoku Ledger - 2026-09-03

## Ten-Level Technique Mapping

The user asked for the Sudoku skills associated with the implemented numeric
difficulty levels.

The canonical technique base levels are defined in
`app/src/main/java/org/secuso/privacyfriendlysudoku/controller/hints/HumanTechnique.java`.
The final rating is calculated in
`app/src/main/java/org/secuso/privacyfriendlysudoku/controller/hints/HumanDifficultyRater.java`.

| Level | Category | Techniques or solving profile |
|---:|---|---|
| 1 | Beginner | Last Digit and obvious Naked Singles, with generous clues or many available basic moves |
| 2 | Beginner | Last Digit and Naked Singles only, but with fewer clues, fewer simultaneous moves, or a longer forced-singles path |
| 3 | Easy | A small number of Hidden Singles |
| 4 | Easy | Heavier Hidden-Single work and the introduction of Pointing Candidates and Claiming Candidates |
| 5 | Moderate | Naked Pairs and Hidden Pairs; repeated locked-candidate work can also raise a puzzle here |
| 6 | Moderate | Naked/Hidden Triples and Quads, or sustained pair/locked-candidate workload |
| 7 | Hard | X-Wing, Skyscraper, and 2-String Kite |
| 8 | Hard | Swordfish, XY-Wing, XYZ-Wing, W-Wing, and Simple Coloring; several Level-7 deductions can also raise a puzzle here |
| 9 | Challenge | Jellyfish, X-Chain, and XY-Chain |
| 10 | Challenge | Forcing Chain or the need for a forcing proof/search after all supported non-forcing techniques are exhausted |

## Interpretation

The levels are puzzle difficulty ratings, not ten isolated lessons. Levels 2,
4, 6, and sometimes 8 distinguish workload within a technique band. For
example, Levels 1 and 2 both use only elementary placements, while Level 2 has
a less forgiving solve path. Likewise, a puzzle with repeated Level-7 deductions
can be rated Level 8 even if it never uses a technique whose base level is 8.

The grader and interactive hint engine share the same ordered
`HumanTechnique` registry. During grading, if all supported non-forcing rules
are exhausted before the puzzle is complete, the rater records that forcing is
required and assigns Level 10; it does not build the full contradiction proof
merely to establish the rating.

## Difficulty Guide Dialog

Added a 48 dp question-mark help button immediately to the right of the main
menu difficulty slider in both portrait and landscape layouts. The slider now
uses the remaining constrained width instead of a fixed width, keeping the
three-control row responsive.

Activating the button opens an app-themed, scrollable alert dialog listing all
ten levels, their five categories, and their associated techniques or workload
profiles. The button has an explicit accessibility description. The displayed
copy preserves the distinction between a newly introduced technique and a
harder workload using techniques from the preceding level.
